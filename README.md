# Online Customer Purchasing Behaviour Analysis

## Aim

To analyze purchasing behaviour among online supermarket customers based on age group, product category, order value, item count, and delivery frequency.

## Dataset

The dataset contains customer order information with the following attributes:

- Order ID
- Age Group
- Product Category
- Order Value (INR)
- Item Count
- Delivery Frequency per Month

## Data Analysis

The following steps were performed using Python and Pandas:

1. Loaded the customer order dataset.
2. Checked the dataset structure and missing values.
3. Identified and removed repeated Order IDs.
4. Handled missing age group and delivery frequency values.
5. Calculated average value per item.
6. Created customer order-frequency groups.
7. Compared order values across age groups.
8. Compared order values across product categories.
9. Analyzed order values across customer frequency groups.
10. Created Box Plot and Bar Charts for visualization.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn
- VS Code

## Key Findings

- The 36–50 age group had the highest average order value.
- Fashion had the highest average order value among product categories.
- Medium-frequency customers had the highest average order value.
- Fashion also had the highest average value per item.

## Visualizations

The project contains:

- Order Value Box Plot by Age Group
- Average Order Value by Product Category
- Average Order Value by Customer Frequency Group

## Conclusion

The analysis helps identify customer groups and product categories with stronger purchasing potential. The findings can be used to create targeted promotional campaigns for high-value customer segments and popular product categories.
